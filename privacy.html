POLICY

Privacy Policy

This policy explains what happens to information when you visit the Syntax Forge website, download a release, or use the current public Windows app.

Effective: August 28, 2026Last updated: August 28, 2026
The short version

The website has no project-run analytics, advertising, account form, or payment system. Course progress and lesson code stay on your computer in the current public build. GitHub hosts the site and downloads, so GitHub receives ordinary network and service data when you visit or download.

1. Who operates Syntax Forge

Syntax Forge is an independently maintained software project published through the GitHub account n3try. In this policy, “Syntax Forge,” “we,” and “us” refer to that project maintainer.

2. What this policy covers

This policy covers the website at n3try.github.io/syntax-forge-downloads and the official Syntax Forge desktop releases linked from it. A third-party website, runtime, or service has its own policy.

3. Information handling

What happens in each part of the service
WebsiteThe site does not contain a project-run account form, contact form, analytics script, advertising tracker, or payment system. We do not receive a visitor database from the site.
Hosting and downloadsGitHub Pages and GitHub Releases deliver the site and files. GitHub may process IP address, device and browser details, request time, pages visited, download requests, cookies, and security logs under its own policies.
Course progressThe current public app saves completed lessons, XP, streaks, preferences, and achievements in a local progress.json file inside the app data folder for your Windows account.
Lesson codeFiles you write in lessons stay in Documents\Syntax Forge Workspace. The current public build does not upload those files.
UpdatesThe installed app contacts the public GitHub Releases feed to check for and download updates. The request does not include course progress, but GitHub receives ordinary network metadata such as an IP address.
Runtime installsIf you choose a guided runtime install, the app starts Microsoft WinGet. Microsoft and the selected package source or software publisher may receive ordinary installation and network data under their own policies.
Cloud accountsGoogle sign-in and cloud sync are not configured in the current public release, so the app does not currently send account or progress data to Google or a Syntax Forge cloud database.

4. Cookies and tracking

Syntax Forge does not add its own cookies, analytics pixels, advertising SDKs, or cross-site tracking code to this website. GitHub may use cookies and similar technologies while providing GitHub Pages and Releases. See the GitHub Privacy Statement and GitHub Cookies notice.

We do not sell personal information or share it for cross-context behavioral advertising.

5. Why information is used

Local app data is used to show your progress, continue lessons, remember learning preferences, and operate the software. GitHub-hosted requests are used by GitHub to deliver and secure the website and release files. WinGet requests are used to install software only after you choose an install action.

6. Storage, retention, and deletion

Because the current public build does not operate a cloud account database, Syntax Forge does not retain a server copy of your course progress or code. Local files remain until you remove them. Uninstalling an app may leave user data behind, so delete the Syntax Forge app data folder and Documents\Syntax Forge Workspace if you also want to remove local progress and lesson files.

GitHub controls retention of its hosting, security, and download logs. Requests involving that data must be directed to GitHub.

7. Security

The site and release downloads use HTTPS through GitHub. Published releases include SHA-256 checksums so you can verify file integrity. No internet service or local application can promise perfect security.

The current Windows installer is not Authenticode-signed. Windows may display an “Unknown publisher” warning. Download only from the official release links on this site.

8. Children’s privacy

The current website and public app do not ask for personal information or enable cloud accounts. We do not knowingly collect personal information directly from children under 13. A parent or guardian should supervise a child’s installation of runtimes, execution of downloaded software, and use of external links.

If cloud accounts are enabled in a future release, this policy and the product’s age handling must be updated before personal information from children is collected.

9. Privacy choices and requests

You can use the current app without an account. You can stop update checks by closing the app, and you control whether to start a runtime installation. You can delete local progress and workspace files from your computer at any time.

For a privacy question, open an item in the project issue tracker. Issues are public, so do not post an email address, account identifier, or other sensitive information. Ask the maintainer for a private contact method if your request requires one.

10. Future cloud accounts

The app contains support for optional Google sign-in and Supabase-backed progress sync, but those services are not configured in the current public build. Before they are activated, this policy must be revised to name the providers and disclose the account fields, synced progress fields, legal basis, retention period, deletion process, security measures, and any international data transfers.

11. Changes to this policy

Material changes will be posted on this page with a new “Last updated” date. Check this page when a release adds accounts, analytics, payments, or another network service.
